方案四 · PC 浏览器 F12 登录态抓取
（淘宝系活动任务参数）

一句话定位：不用手机连线、不用抓包工具。PC Chrome 用手机仿真 + 淘宝登录态直接打开活动页，F12 看网络请求，HAR 导出后本地解析——目前唯一能读到任务接口完整响应的方法。

〇、先看能力边界（是否适用你的目标活动）

活动任务引擎PC 能读?PC 能做任务?说明
芭芭农场任务列表（搜索/互动/浏览）pentaprism✅❌queryitem 响应完整可读
专供会场 / 品牌周 / C2M 店铺页pentaprism✅❌同上
拍拍乐（paipaile）paipaile.echange❌❌端内锁：FAIL_SYS_UNAUTHORIZED_ENTRANCE
摇钱树（moneytree）yaoqianshu❌❌端内锁，同上

「PC 能读 ≠ 能做任务」：所有写入操作（trigger 领进度、settle 结算）在 PC 一律被风控拒绝，报 REQUEST_SOURCE_REJECT / BIZ_FAIL_NO_SAFE / -1002「大家太热情了」。本方案的用途是看参数、看规则、看次数，做任务还是要回手机。

一、准备（2 分钟）

  1. PC 最新版 Chrome（Edge 也可，F12 操作相同）
  2. 一个登录过手机淘宝的账号

二、核心七步

第 1 步：登录淘宝 PC 站

打开 https://www.taobao.com → 左上角「亲，请登录」→ 手机淘宝扫码登录。登录态会带到所有 *.m.taobao.com 子域。

第 2 步：切手机仿真

按 Ctrl + Shift + M（设备工具栏），顶部下拉随便选一个手机机型（如 iPhone SE），页面自动按手机版渲染。切完按 F5 刷新一次。

第 3 步：打开 F12 Network

按 F12 → 切到 Network 标签。建议先把两个勾打上：

  • Preserve log（保留日志）—— 跳转后记录不清空
  • Disable cache（禁用缓存）—— 保证请求重新发出

第 4 步：粘贴活动链接打开

把任务加载链接粘到地址栏回车。链接来源（三选一）：

  • 方案一入口一：手机 logcat 抓到的任务 URL，直接搬过来
  • 页面跳转链接：F12 Network 里右键请求 → Copy → Copy link address
  • 会场全局搜索：F12 里 Ctrl+Shift+F 打开 Search 面板，搜 deliveryId，双击结果直达

第 5 步：触发任务请求

页面出来后，点击任务卡片、商品、或直接 F5 刷新——观察 Network 里出现：

queryitem ← 任务详情（重点，含次数和奖励规则） scene.query ← 任务列表（一次返回全部任务） trigger / award / report ← 做任务/领奖（PC 会被拒，看参数够用）

第 6 步：看单条响应

过滤框输入 queryitem → 点中请求 → 右侧 Response（或 Preview）面板直接读 JSON。想复制全文：右键请求 → Copy → Copy response。

第 7 步：导出全量 HAR

Network 面板空白处右键（或点 ⬇ 图标）→ Save all as HAR with content。得到 .har / .devtools 文件，发给电脑上的 Python 解析。

灰色请求点不开？那是录制开始前发生的请求或缓存。解决：勾 Preserve log + Disable cache 后 F5，让请求重新发一遍。

三、HAR 本地解析（Python 脚本）

导出的 .devtools / .har 文件本质是 JSON，直接解析。下面脚本一键提取全部任务档案：

import json, re, sys f = sys.argv[1] # python3 parse_har.py 123.devtools d = json.load(open(f, encoding="utf-8", errors="ignore")) entries = d["log"]["entries"] for e in entries: u = e["request"]["url"] if "queryitem" not in u.lower() and "scene.query" not in u.lower(): continue t = e["response"].get("content", {}).get("text", "") for m in re.finditer(r'\{"id":(\d+)[^\{\}]*?"taskParams":\{[^}]*\}', t): print(m.group(0)[:500]) # 次数与奖励 for m in re.finditer(r'"progress":\{[^}]*\}', t): print(m.group(0)) for m in re.finditer(r'"displayAwardMode":\{[^}]*\}', t): print(m.group(0))

四、queryitem 响应字段解读（核心）

字段含义注意
iddeliveryId，任务钥匙结算归因用
taskParams.sceneId场景钥匙和 deliveryId 成对
taskParams.fromToken按次签发的会话凭证会轮换，不是常量
taskParams.implId实例 ID格式 other_<period>_<用户/0>_<deliveryId>_<序号>；cloudsail_ 前缀 = 广告按次下发，每次都变
progress.maxTimes / needTimes / times每日上限 / 完成所需 / 已完成每日次数看这里
rewards[].result.displayAwardMode奖励引擎上限 {max, min}比实际展示大，如肥料 300000 vs 100000
rewards[].result.displayMaxCount当前档位奖励页面说的「最高得」
groupId / configId配置族 / 配置号同 groupId = 同配置孪生实例（如 75081/75085/93820 同为 34832）
nextTaskList / secondTaskInfo服务端把下一个任务写进响应顺藤摸瓜拿新 deliveryId
bucketNo动态规则版本号如 farmDynamicRuleVer4
taskSubTypeONCE / 每日循环等

五、pentaprism 接口族速查

mtop.taobao.pentaprism.scene.query ← 任务列表（一次拿全部任务） mtop.taobao.pentaprism.scene.queryItem ← 任务详情（次数/奖励/凭证） mtop.taobao.pentaprism.scene.receive ← 接任务 mtop.taobao.pentaprism.scene.trigger ← 做任务（进度+1，PC 被拒） mtop.taobao.pentaprism.scene.award ← 领奖 mtop.taobao.pentaprism.scene.report ← 行为上报 mtop.taobao.pentaprism.scene.queryClick ← 点击流归因 状态机：receive 接单 → trigger 做任务(每次+1) → award 领奖

报错码对照

报错真实含义
REQUEST_SOURCE_REJECT: h5 request forbiddenPC 写入被拒（trigger）
BIZ_FAIL_NO_SAFE:: 网络拥堵，请稍后再试风控委婉话术，同上
-1002:: 大家太热情了，请稍后再试settle 结算被风控
FAIL_SYS_UNAUTHORIZED_ENTRANCE:: API访问入口未授权端内专属接口，PC 读都锁死（拍拍乐/摇钱树）

六、配套方法（同一套 F12）

  • JS 逆向：Network 里点 JS 请求 → 响应直接 Copy 存本地，全局搜 mtop 接口名 / deliveryId，可挖出页面没发的接口清单（如 pentaprism 五件套就是从 c2m_shop.js 的枚举表里挖到的）。alicdn 上的 JS 是公开 CDN，curl 可直接下载。
  • 拿「其他」任务：会场里每换一个任务卡片，过滤 queryitem，响应里的 deliveryId + secondTaskDeliveryId 就是当页全部钥匙。
  • 拍拍乐/摇钱树/支付宝：本方案失效，改走手机端（logcat 抓端内跳转 URL，见方案一入口一；支付宝页面源码，见方案一入口二）。

七、常见坑速查

  1. Network 请求灰色不可点 → 勾 Preserve log + Disable cache，F5 重放
  2. 导出的 .devtools 打不开 → 它就是 HAR JSON，用 Python json.load 直接读
  3. fromToken 每次不一样 → 正常，按次签发；拿它构造链接要现抓现用
  4. 页面奖励数字很大 → 那是引擎上限，实际「以获得为准」，看 displayMaxCount
  5. 同一个任务两个卡片 → 可能是同配置孪生实例（同 groupId 不同 deliveryId），也可能真是两个任务，看跳转 URL 里的 deliveryId 是否相同
  6. implId 带 cloudsail_ 前缀 → 广告按次下发，每次都不一样，别当常量记录
