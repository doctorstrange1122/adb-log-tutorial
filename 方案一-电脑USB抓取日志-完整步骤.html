方案一 · 电脑抓取淘宝 / 支付宝活动参数（完整步骤）

两个入口分成两套做法：淘宝 / 天猫 用 ADB 抓日志；支付宝农场 / 助农 用抓页面源码（免 root）
环境：Windows 系统 + 鸿蒙 2/3/4.x 手机（AOSP 兼容版）

入口区分（先看这一节，别混用）

入口 要抓的东西 用哪一节 关键参数
入口 A
淘宝 / 天猫		 活动落地 URL、埋点链接 第三节
ADB logcat 抓日志		 sceneId、deliveryId、spmb
入口 B
支付宝（芭芭农场 / 助农）		 活动页里的任务配置 第四节
抓 H5 页面源码		 orderDeliveryId、visitDeliveryId、visitSceneId、shareType=BABAFarm
为什么两套做法不一样：支付宝的活动页其实是托管在 pages.tmall.com 的 H5，参数直接内联在页面的 window.$data 里，不经过 App 日志。所以 ADB logcat、dumpsys、uiautomator 都抓不到；只能直接请求页面或看页面源码。
参数不是一套：淘宝侧叫 deliveryId / sceneId；支付宝活动页按任务拆成 orderDeliveryId（下单任务）和 visitDeliveryId（浏览/到访任务）。两边共用的是活动 ID（如 100085），不是同一套字段。

一、下载安装 ADB 工具（入口 A 需要）

渠道一：Android 官网（推荐）

浏览器打开：

https://developer.android.google.cn/tools/releases/platform-tools

页面找到「Download SDK Platform-Tools for Windows」，点击下载。

渠道二：Google 直链下载

https://dl.google.com/android/repository/platform-tools-latest-windows.zip

渠道三：国内镜像（清华）

https://mirrors.tuna.tsinghua.edu.cn/AOSP/platform-tools/

找到最新的 platform-tools-windows.zip，下载后解压到 E:\adb 目录。

解压目录约定：统一解压到 E:\adb，解压后路径应为 E:\adb\platform-tools\adb.exe，但本教程命令直接用 E:\adb\adb.exe（建议把 platform-tools 里的 adb.exe 复制一份到 E:\adb\ 根目录，方便调用）。

二、手机开启 USB 调试（入口 A 需要）

  1. 设置 → 关于手机 → 连点版本号 7 次（开启开发者模式）
  2. 设置 → 系统和更新 → 开发人员选项
  3. 开启「USB调试」
  4. 数据线连电脑（选「传输文件 / MTP」模式，不要选仅充电）
  5. 手机弹窗「是否允许 USB 调试」→ 勾「一律允许」→ 点允许

三、入口 A：淘宝 / 天猫 —— ADB 抓日志

1. 验证设备连接

电脑 cmd 执行：

E:\adb\adb.exe devices

看到类似下面的输出表示连上了：

List of devices attached xxxxxxxx device

2. 清空旧日志

清掉缓冲区，避免抓到无关旧日志：

E:\adb\adb.exe logcat -c

3. 开始抓取（按需选一种）

方式 A：HTTP 通用过滤（推荐先试这个）

E:\adb\adb.exe logcat -v time | findstr /i "http"

方式 B：淘宝专用过滤（抓 sceneId / deliveryId）

E:\adb\adb.exe logcat -v time | findstr /i "taobao tb.cn pages.m item.htm sceneId deliveryId"

方式 C：全部日志存文件（不过滤，事后 grep）

E:\adb\adb.exe logcat -v time > E:\taobao-crawler\adb-log.txt
目录需提前建好：方式 C 输出到 E:\taobao-crawler\，先在 cmd 跑 mkdir E:\taobao-crawler 建目录，否则会报错。

4. 在手机上操作（任意按钮或页面）

  • 打开目标 App（淘宝 / 天猫 / 任意应用）
  • 点击任意想要抓取的按钮或页面（如「领红包下单」「芭芭农场」「任务」等）
  • 每点一次，cmd 窗口会实时滚出对应的 URL 和参数
  • 需要抓多个按钮，就依次点击；每个按钮的加载链接都会单独出现在日志里

5. 停止抓取

cmd 窗口按 Ctrl+C 停止。

6. 查找 spmb 链接（图形界面方式）

如果用的是方式 C（保存到文件），按下面步骤：

① 打开日志文件

打开文件夹 E:\taobao-crawler\，找到 adb-log.txt，双击用记事本打开。

notepad E:\taobao-crawler\adb-log.txt

（或者在 cmd 里直接执行上面这条命令打开）

② 调出查找

记事本打开后，按快捷键 Ctrl+F（或菜单「编辑 → 查找」），弹出查找框。

③ 输入关键词

查找内容输入：

spmb

④ 反复点「查找下一个」

  • 点一次「查找下一个」→ 跳到第一个包含 spmb 的位置
  • 继续点「查找下一个」→ 依次跳到第 2、3、4……个
  • 一直点，直到提示「找不到」为止
  • 提示找不到时，光标停的位置就是最后一个包含 spmb 的链接
关键操作：当记事本提示「找不到 "spmb"」时，说明已经查找到末尾，当前停留在屏幕上的那行就是最后一个含 spmb 的链接。整行复制下来即可。

⑤ 复制目标链接

找到最后一行后，整行选中 → Ctrl+C 复制，这就是你要的链接。

注意：spmb 是淘宝的 SPM 埋点参数（页面追踪 ID），通常出现在 URL 的 &spmb= 或 ?spmb= 里。例如： https://pages-fast.m.taobao.com/...?...&spmb=46023237&...

三-补充：电脑无线抓日志（鸿蒙手机适用，免插数据线）

适用场景：鸿蒙 2/3/4.x 手机 + 电脑在同一 Wi-Fi。首次用 USB 激活一次 5555 端口后，拔掉 USB 也能无线抓日志，不用一直插着线。
前提：鸿蒙手机没有原生「无线调试」开关，必须先用 USB 连电脑跑一次 adb tcpip 5555 激活端口。手机一旦重启，5555 监听失效，需重新插电脑激活。

① 一次性激活 5555 端口（USB 插着时）

先按「二、手机开启 USB 调试」连上 USB，确认 adb devices 能看到设备。

电脑 cmd 执行：

E:\adb\adb.exe tcpip 5555

看到下面输出表示激活成功：

restarting in TCP mode port: 5555

② 查手机 IP

E:\adb\adb.exe shell ip -f inet addr show wlan0

输出里找 inet 192.168.x.x（不是 .255，那是广播地址），记下这个 IP。

③ 拔掉 USB，无线连接

E:\adb\adb.exe connect 192.168.x.x:5555

把 192.168.x.x 换成第②步查到的真实 IP。

④ 验证连接

E:\adb\adb.exe devices

看到 192.168.x.x:5555 device 就无线连上了。

⑤ 抓日志（和 USB 方式完全一样）

E:\adb\adb.exe -s 192.168.x.x:5555 logcat -c

实时过滤：

E:\adb\adb.exe -s 192.168.x.x:5555 logcat -v time | findstr /i "taobao sceneId deliveryId spmb"

或存文件：

E:\adb\adb.exe -s 192.168.x.x:5555 logcat -v time > E:\taobao-crawler\adb-log.txt
注意：无线连接时 adb devices 里设备是 192.168.x.x:5555 这种形式，如果同时还有 USB 设备，要用 -s 指定目标，否则会报 more than one device。

⑥ 手机重启后恢复

手机一旦重启，5555 监听消失，必须重新插电脑激活：

E:\adb\adb.exe tcpip 5555

然后从第③步继续（connect IP）。

简化记忆：只要手机没重启，电脑和手机在同一 Wi-Fi，随时 adb connect IP:5555 就能抓，不用插 USB。

四、入口 B：支付宝（芭芭农场 / 助农）—— 抓 H5 页面源码

全程不需要 ADB、不需要 root、不需要抓包证书。只要能拿到活动页那条链接，用电脑 curl 或者手机浏览器就能把参数读出来。

原理一句话

支付宝农场/助农的活动页是 SSR 页面，活动配置（含任务 ID）被直接内联进 HTML 的 window.$data 变量里。请求到这个 URL，就能在返回的 HTML 里搜到 orderDeliveryId / visitDeliveryId / visitSceneId。

第 1 步：拿到活动页长链（展开支付宝分享短链）

支付宝分享/复制出来的链接通常有两种短链形态：

https://codeapp.alipay.com/s/xxxxxxx
https://ur.alipay.com/_xxxxxxxx

把它展开成真实落地地址（电脑 cmd 执行，把链接换成你自己的）：

curl -sL -w "\nFINAL=%{url_effective}\n" -A "Mozilla/5.0 (Linux; Android 12; PCT-AL10) AppleWebKit/537.36 Chrome/120.0 Mobile AlipayGphone/10.5.76" "https://codeapp.alipay.com/s/xxxxxxx"
必须在 cmd 里直接执行（不要写成 .bat 文件），因为 %{url_effective} 在批处理里会被当成变量需要转义成 %%。

输出末尾的 FINAL= 后面就是落地协议，长这样：

alipays://platformapi/startapp?appId=20000067&url=https%3A%2F%2Fpages.tmall.com%2Fwow%2Fz%2Fhdwk%2Falipayfarm%2F2026-activity%3Ftype%3Dvisit%26source%3Dbaixianbaipin_share&apshareid=2fcddb82-7d06-4869-bf4c-ee2093149729&shareBizType=BABAFarm

里面 url= 后面那一段（到 &apshareid 之前）就是活动页长链，是 URL 编码的，解码一下：

powershell -NoProfile -Command "[uri]::UnescapeDataString('https%3A%2F%2Fpages.tmall.com%2Fwow%2Fz%2Fhdwk%2Falipayfarm%2F2026-activity%3Ftype%3Dvisit%26source%3Dbaixianbaipin_share')"

解码后得到：

https://pages.tmall.com/wow/z/hdwk/alipayfarm/2026-activity?type=visit&source=baixianbaipin_share
活动页路径会变：alipayfarm/2026-activity 只是当前这一场。以你自己分享链展开后 url= 解码出来的地址为准，不要照抄。

第 2 步：下载活动页 HTML

先建输出目录：

mkdir E:\alipay-crawler

下载页面（URL 带 &，一定要加双引号）：

curl -s -A "Mozilla/5.0 (Linux; Android 12; PCT-AL10) AppleWebKit/537.36 Chrome/120.0 Mobile AlipayGphone/10.5.76" "https://pages.tmall.com/wow/z/hdwk/alipayfarm/2026-activity?type=visit&source=baixianbaipin_share" -o E:\alipay-crawler\farm.html

确认文件拿到（正常会有 200 KB 左右）：

dir E:\alipay-crawler\farm.html

第 3 步：直接查参数（一条命令出结果）

findstr /i "orderDeliveryId visitDeliveryId visitSceneId orderSceneId shareType orderTaskCode" E:\alipay-crawler\farm.html

一次查全部任务配置：

findstr /i "taskConfig" E:\alipay-crawler\farm.html

结果太长就导出成单独文件再看：

findstr /i "orderDeliveryId visitDeliveryId visitSceneId" E:\alipay-crawler\farm.html > E:\alipay-crawler\delivery-id.txt
notepad E:\alipay-crawler\delivery-id.txt
实测结果（当前这版助农活动页）
orderDeliveryId=104283（下单任务）
visitDeliveryId=104321（浏览/到访任务）
visitSceneId=10021、orderSceneId=10021
shareType=BABAFarm、orderTaskCode=alipay_live_order_task_high

第 4 步（更省事的备用做法）：浏览器直接看

不需要 ADB、不需要 root。电脑或手机浏览器都能用，手机浏览器一样可以。
  1. 浏览器打开解码后的活动页长链
  2. 直接 Ctrl+F 搜关键词
  3. 或按 F12 打开控制台，输入下面这条命令回车，直接打印整份配置
window.$data

只想看任务 ID：

JSON.stringify(window.$data).match(/orderDeliveryId[^,]*/g)

参数说明与两入口对照

参数 含义 支付宝农场实测 淘宝侧对应
orderDeliveryId 下单任务的投放/任务 ID 104283 deliveryId
visitDeliveryId 浏览（到访）任务的投放 ID 104321 deliveryId
visitSceneId / orderSceneId 任务所属场景 ID 10021 sceneId
activityId / hd_from_id 活动本体 ID（两端共用） 100085 hd_from_id
shareType 分享业务标识 BABAFarm —
apshareid / fromToken 用户归因（谁分享的） UUID / token fromToken
别搞混：orderDeliveryId、visitDeliveryId、sceneId 都是活动常量（所有人一样），不是“谁帮你助力”的归因参数。用户归因在 apshareid（支付宝）或 fromToken（淘宝），而且不在页面配置里。

跨端跳转链接的样子（参考）

淘宝端“去支付宝做任务”这类链接是淘宝自己的 dps:// 协议包裹活动页，参数同样在 URL 里：

dps://p?url=https%3A%2F%2Fpages-fast.m.taobao.com%2Fwow%2Fz%2Fhdwk%2Ffarm-ssr%2Ftmfarm%3F...%26hd_from%3Dalipay_mayifarm%26hd_from_id%3D100085%26sceneId%3D3646%26activityId%3D100085%26deliveryId%3D58298%26implId%3Dother_1430_2892009_58298_0

用同样的方法把 url= 解码，就能看到 sceneId=3646、deliveryId=58298、activityId=100085。

五、常见问题

Q: adb devices 显示 unauthorized？
A: 手机屏幕解锁，看有没有弹授权窗。没弹就去 设置→开发人员选项→撤销USB调试授权，重新插 USB。

Q: adb devices 列表是空的？
A: 1) 检查 USB 模式是不是「传输文件」
2) 换数据线（很多线只能充电）
3) 换 USB 口

Q: 'findstr' 不是内部或外部命令？
A: 你在 PowerShell 里跑的，换 cmd 即可。开始菜单搜「cmd」打开。

Q: 抓不到淘宝相关日志？
A: 1) 确认手机系统是鸿蒙 2/3/4.x（AOSP 兼容版）
2) 鸿蒙 7.0（纯血）没有 logcat，需用 hdc
3) 操作淘宝时 cmd 窗口保持开启，别关掉

Q: 支付宝的 orderDeliveryId 为什么 ADB 抓不到？
A: 它是活动页的配置项，不走 App 日志；dumpsys 和 uiautomator 也读不到 WebView 内部的 URL。用第四节的页面源码方式。

Q: findstr 在 farm.html 里什么都没搜到？
A: 1) 确认解码后的地址是 pages.tmall.com 或 pages-fast.m.taobao.com 的 wow/z/ 活动页
2) 部分活动不是 SSR 渲染，改用浏览器 F12 打印 window.$data
3) 检查下载的 html 大小（几 KB 说明被拦或跳转了）

Q: curl 提示不是内部或外部命令？
A: Windows 10 1803 以上自带 curl。老系统去装 curl，或直接用浏览器打开页面另存为 html。

Q: cmd 一闪就关了？
A: 别双击 cmd 启动，开始菜单搜「cmd」→ 回车打开，再 cd 到对应目录。

六、目标链接示例（按入口分开看）

入口 A · 淘宝 抓到的 URL 大致长这样，里面有 sceneId 和 deliveryId：

https://pages-fast.m.taobao.com/wow/z/app/ltao-fe/tbms-cooperation/home?ut_sk=...&deliveryId=75085&...&sceneId=7980&...

入口 B · 支付宝 活动页 HTML 里挖出来的是任务配置，不是 URL 参数：

"shareType":"BABAFarm","visitDeliveryId":"104321","orderDeliveryId":"104283","visitSceneId":"10021","orderSceneId":"10021","orderTaskCode":"alipay_live_order_task_high"

关键提示

  • 先定入口：淘宝/天猫走 ADB（第三节），支付宝农场/助农走页面源码（第四节）
  • 抓 ADB 期间手机别熄屏太久（Wi-Fi 可能断）
  • 每点一次按钮，cmd 会实时输出，盯着窗口看
  • ADB 方式 C 最稳，事后用 findstr 检索
  • 支付宝方式不用设备、不用 root，一条 curl 就够
  • 活动页路径和 ID 每期活动都会变，以当次分享链展开结果为准
  • sceneId / deliveryId / orderDeliveryId 是活动常量，不是用户归因
