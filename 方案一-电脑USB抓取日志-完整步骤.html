方案一 · 电脑抓取活动参数

两个二级入口，按你要抓的 App 选一个进入，进入后才有完整步骤
环境：Windows 系统 · 鸿蒙 2/3/4.x 手机（AOSP 兼容版）· Android 5+

入口① 淘宝 / 天猫 ADB 日志

适用场景：抓淘宝 / 天猫活动落地 URL、埋点链接

需要：电脑 + USB 数据线 + 手机开启 USB 调试

能抓到：sceneId、deliveryId、spmb

特点：实时输出，点哪个按钮抓哪个，还能无线抓

查看完整步骤 →

入口② 支付宝 免 root

适用场景：抓支付宝芭芭农场 / 助农活动页的任务参数

需要：只要一条活动页分享链接（不用 ADB、不用 USB 调试）

能抓到：orderDeliveryId、visitDeliveryId、visitSceneId、shareType=BABAFarm

特点：一条 curl 或浏览器 F12 即可，手机也能做

两个入口对比

对比项 入口① 淘宝 / 天猫 入口② 支付宝
用到的工具 adb.exe + logcat curl / 浏览器，不需要 adb
前提条件 USB 调试、数据线、手机连电脑 能拿到活动页分享链接
参数出现位置 App 日志里的 URL 页面 HTML 的 window.$data
是否要 root 不要 不要
两个入口不能混用：淘宝的参数（sceneId / deliveryId）出现在 URL 和日志里；支付宝的活动参数在页面配置里，ADB 日志、dumpsys、uiautomator 都读不到。选错入口会一直抓不到。
