手机端自己抓自己日志 - 完整步骤

适用：华为/荣耀等鸿蒙系统手机（AOSP 兼容版，非纯血鸿蒙7.0）
原理：电脑 USB 激活 5555 端口后，断开 USB，手机 Termux 连自己 IP 抓 logcat

一、首次设置（每台手机做一次）

1. 电脑激活 5555 端口

电脑 cmd（USB 连手机）逐条执行（先跑①确认设备连上，再跑②）：

① 确认设备（看到 device 字样才继续）

E:\adb\adb.exe devices

② 切换到 TCP 模式

E:\adb\adb.exe tcpip 5555

2. 手机查 IP

设置 → 关于手机 → 状态信息 → IP 地址（例如 192.168.3.50，记下来）

3. 手机装 Termux

应用市场搜 Termux 安装

4. Termux 装工具

在 Termux 里执行：

pkg install android-tools -y

5. Termux 加电池白名单

设置 → 应用 → Termux → 电池 → 无限制

设置 → 电池 → 启动管理 → Termux → 手动管理 → 三开关全开

二、每次抓日志（重复执行）

6. 开 Termux，加锁防挂

termux-wake-lock

7. 连接自己

把 192.168.3.50 换成自己的 IP：

adb connect 192.168.3.50:5555

8. 首次需授权（只弹一次）

看手机屏幕弹窗 → 勾「一律允许使用这台计算机进行调试」→ 点「允许」

9. 验证

adb devices

看到 192.168.3.50:5555 device 即可

10. 设默认设备 + 清旧日志

① 设默认设备

export ANDROID_SERIAL=192.168.3.50:5555

② 清空旧日志

adb logcat -c

11. 后台存文件

adb logcat -v time > ~/taobao-log.txt &

12. 实时过滤显示

adb logcat -v time | grep -i "taobao\|sceneId\|deliveryId\|loadUrl\|startApp"

13. 在手机上操作（任意按钮或页面）

  • 打开目标 App（淘宝 / 天猫 / 任意应用）
  • 点击任意想要抓取的按钮或页面（如「领红包下单」「芭芭农场」「任务」等）
  • 每点一次，Termux 会实时滚出对应的 URL 和参数
  • 需要抓多个按钮，就依次点击；每个按钮的加载链接都会单独出现在日志里

14. 停止抓取

Termux 里按 Ctrl+C

15. 查文件抓到啥（命令行方式）

查找 sceneId / deliveryId / pages-fast：

grep -i "sceneId\|deliveryId\|pages-fast" ~/taobao-log.txt

查找 spmb 关键词：

grep -i "spmb" ~/taobao-log.txt

查找结果导出到单独文件方便查看：

grep -i "sceneId\|deliveryId\|spmb" ~/taobao-log.txt > ~/scene-id.txt

16. 查找最后一个 spmb 链接（文件查看方式）

用 Termux 内置文本编辑器打开日志文件：

nano ~/taobao-log.txt

在 nano 里查找 spmb：

  • 按 Ctrl+W（搜索快捷键）
  • 输入：spmb
  • 按回车 → 跳到第一个匹配位置
  • 继续按 Ctrl+W → 直接回车 → 跳到下一个
  • 重复操作，直到提示「not found」为止
  • 提示「not found」时，光标停的位置就是最后一个含 spmb 的链接
关键操作：当 nano 提示「[ "spmb" not found ]」时，说明已到末尾，当前光标所在的行就是最后一个含 spmb 的链接。整行复制即可。

退出 nano：Ctrl+X（不保存直接退）

17. 用手机文本编辑器查看（推荐，更直观）

Termux 把日志文件放到手机能访问的目录：

cp ~/taobao-log.txt /sdcard/taobao-log.txt

然后用手机文件管理器或文本编辑器打开：

  • 文件管理器 → 内部存储 → 找到 taobao-log.txt
  • 长按 → 用文本编辑器打开（推荐 WPS、QuickEdit、MT 管理器）
  • 用编辑器的「查找」功能搜 spmb
  • 反复点「下一个」→ 最后一个就是目标链接
注意：spmb 是淘宝 SPM 埋点参数（页面追踪 ID），通常出现在 URL 的 &spmb= 或 ?spmb= 里。例如： https://pages-fast.m.taobao.com/...?...&spmb=46023237&...

三、Termux 被杀后再开（不用电脑）

逐条执行：

termux-wake-lock
adb connect 192.168.3.50:5555
export ANDROID_SERIAL=192.168.3.50:5555
adb logcat -c
adb logcat -v time | grep -i "taobao\|sceneId\|deliveryId"

四、手机重启后（必须回电脑）

5555 失效，电脑 cmd 执行：

E:\adb\adb.exe tcpip 5555

然后从第 6 步继续。

关键提示

  • IP 换成自己的（每台手机不一样）
  • 手机别重启，重启就要回电脑激活一次
  • Termux 别被杀，加电池白名单 + termux-wake-lock
  • 两台手机互换抓，把 IP 对调即可

常见问题

Q: adb connect 提示 Connection refused？
A: 5555 端口失效了，回电脑执行 adb tcpip 5555 重新激活

Q: adb devices 提示 unauthorized？
A: 看目标机屏幕有没有弹授权窗，没弹就去 设置→开发人员选项→撤销USB调试授权，然后重连

Q: adb logcat -c 提示 more than one device/emulator？
A: 有多个设备，用 -s 指定，或 export ANDROID_SERIAL=IP:5555

Q: 拔掉 USB 后还能连？
A: 能，只要手机没重启，5555 监听一直在

Q: 抓不到淘宝日志？
A: 检查目标机系统版本：

  • 鸿蒙 2/3/4.x：能抓（AOSP 兼容）
  • 鸿蒙 7.0（纯血）：不能抓，没 logcat，只能用 hdc
