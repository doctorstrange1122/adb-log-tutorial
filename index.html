ADB 抓取日志完整教程

四种方案：方案一二三在手机端抓日志，方案四用电脑浏览器直接看接口

方案一：电脑 USB 抓取 最通用

适用场景：电脑 + 任意能 USB 调试的手机

系统要求：鸿蒙 2/3/4.x、Android 5+ 任意版本

特点：全程插 USB，最稳定，适合一次性抓取

查看完整步骤 →

方案二：鸿蒙手机自抓自

适用场景：华为 / 荣耀手机（鸿蒙系统）

系统要求：鸿蒙 2/3/4.x（AOSP 兼容版，非纯血鸿蒙7.0）

特点：电脑激活一次 5555 端口后，断开 USB 用 Termux 抓，重启后需重新激活

查看完整步骤 →

方案三：原生安卓手机自抓自 最省事

适用场景：小米 / OPPO / vivo / 三星 / 一加 等

系统要求：Android 11+ 原生系统，支持「无线调试」

特点：自带无线调试，全程不用电脑，重启后直接重连

查看完整步骤 →

方案四：PC 浏览器 F12 登录态抓取 最新

适用场景：淘宝系活动任务参数（芭芭农场 / 专供会场 / 品牌周 / C2M 等 pentaprism 体系）

系统要求：只需 PC Chrome + 淘宝账号扫码登录，不用连手机

特点：手机仿真 + F12 看 queryitem 响应 + HAR 导出解析，能读每日次数、奖励规则、deliveryId 全套钥匙；注意只能「读」不能「做任务」（trigger 被风控拒），拍拍乐/摇钱树/支付宝不适用

查看完整步骤 →

四套方案对比

方案 适用机型/场景 需要电脑 需要手机
方案一 任意能 USB 调试 ✅ 必须 ✅ USB 连接
方案二 鸿蒙 2/3/4.x ⚠️ 仅激活一次 ✅ 激活后独立抓
方案三 Android 11+ ❌ 不用 ✅ 手机独立抓
方案四 淘宝系活动（不限机型） ✅ 全程 ❌ 不用（仅扫码登录一次）

💡 方案一二三抓的是手机端日志（URL 入口）；方案四抓的是接口完整响应（次数/奖励/凭证）。实战组合：手机抓任务 URL（方案一）→ 电脑打开链接看响应（方案四）。
