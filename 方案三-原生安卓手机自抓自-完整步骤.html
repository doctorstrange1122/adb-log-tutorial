原生安卓手机自己抓自己日志 - 完整步骤

适用：原生安卓 / 小米 / OPPO / vivo / 三星 / 一加 等支持「无线调试」的 Android 11+ 手机
原理：手机自带无线调试功能，Termux 直接 adb connect 自己 IP 抓 logcat，全程不用电脑

核心优势：相比华为/荣耀鸿蒙方案，原生安卓手机自带无线调试，不需要电脑 USB 激活，重启后也能直接连，更省事。

一、首次设置（每台手机做一次）

1. 开启开发者选项

  1. 设置 → 关于手机（或 我的设备）
  2. 找到「版本号」（MIUI / ColorOS / OriginOS 等可能在不同位置）
  3. 连点 7 次，提示「您已处于开发者模式」

2. 开启无线调试

  1. 设置 → 系统 → 开发者选项（部分机型在 设置 → 更多设置 → 开发者选项）
  2. 找到「无线调试」开关，打开它
  3. 弹窗点「允许」
关键区别：原生安卓 11+ 才有「无线调试」开关。如果开发者选项里找不到，说明系统版本低于 Android 11，或厂商裁了（华为/荣耀就没有）。可以先看 设置 → 关于手机 → Android 版本。

3. 配对一次（拿到配对码）

  1. 点击「无线调试」进入详情页
  2. 点「使用配对码配对设备」
  3. 屏幕显示：配对码（6位数字）、Wi-Fi 配对端口（如 43211）
  4. 记下这两个数，待会用

4. 装 Termux

应用市场搜 Termux 安装（建议装 F-Droid 版本，权限更全）。

5. Termux 装工具

在 Termux 里执行：

pkg install android-tools -y

6. 查手机 IP

在「无线调试」详情页顶部能看到 IP 和端口，例如 192.168.1.108:43211。

或在 Termux 里查：

ip addr show wlan0 | grep inet

输出里 inet 192.168.x.x 就是本机 IP。

7. Termux 加电池白名单

设置 → 应用 → Termux → 电池 → 无限制
设置 → 电池 → 后台管理 → Termux → 不限制（或常驻后台）

二、首次配对（只做一次）

注意：第一次连接需要配对，之后就不用配对了，只用 adb connect 就行。

8. 配对设备

Termux 里执行（IP 和端口换成「无线调试」详情页显示的）：

adb pair 192.168.1.108:43211

提示输入配对码时，输入刚才看到的 6 位数字，回车。

看到 Successfully paired to ... 就配对成功。

三、每次抓日志（重复执行）

9. 开 Termux，加锁防挂

termux-wake-lock

10. 连接自己

（注意：这里是连接端口，不是配对端口；无线调试详情页会同时显示两个端口，连接用大端口的那个，通常是 :5555 或 :xxxxx）

adb connect 192.168.1.108:5555

11. 验证

adb devices

看到 192.168.1.108:5555 device 即可。

12. 设默认设备 + 清旧日志

① 设默认设备

export ANDROID_SERIAL=192.168.1.108:5555

② 清空旧日志

adb logcat -c

13. 后台存文件

adb logcat -v time > ~/taobao-log.txt &

14. 实时过滤显示

adb logcat -v time | grep -i "taobao\|sceneId\|deliveryId\|loadUrl\|startApp\|spmb"

15. 在手机上操作（任意按钮或页面）

  • 打开目标 App（淘宝 / 天猫 / 任意应用）
  • 点击任意想要抓取的按钮或页面（如「领红包下单」「芭芭农场」「任务」等）
  • 每点一次，Termux 会实时滚出对应的 URL 和参数
  • 需要抓多个按钮，就依次点击；每个按钮的加载链接都会单独出现在日志里

16. 停止抓取

Termux 里按 Ctrl+C

17. 查文件抓到啥（命令行方式）

查找 sceneId / deliveryId / pages-fast：

grep -i "sceneId\|deliveryId\|pages-fast" ~/taobao-log.txt

查找 spmb 关键词：

grep -i "spmb" ~/taobao-log.txt

查找结果导出到单独文件：

grep -i "sceneId\|deliveryId\|spmb" ~/taobao-log.txt > ~/scene-id.txt

18. 查找最后一个 spmb 链接（nano 编辑器方式）

用 Termux 内置编辑器打开日志：

nano ~/taobao-log.txt

在 nano 里查找 spmb：

  • 按 Ctrl+W（搜索快捷键）
  • 输入：spmb
  • 按回车 → 跳到第一个匹配位置
  • 继续按 Ctrl+W → 直接回车 → 跳到下一个
  • 重复操作，直到提示「not found」为止
  • 提示「not found」时，光标停的位置就是最后一个含 spmb 的链接
关键操作：当 nano 提示「[ "spmb" not found ]」时，说明已到末尾，当前光标所在的行就是最后一个含 spmb 的链接。整行复制即可。

退出 nano：Ctrl+X

19. 用手机文本编辑器查看（推荐，更直观）

把日志文件复制到手机能访问的目录：

cp ~/taobao-log.txt /sdcard/taobao-log.txt

然后用手机文件管理器或文本编辑器打开：

  • 文件管理器 → 内部存储 → 找到 taobao-log.txt
  • 长按 → 用文本编辑器打开（推荐 WPS、QuickEdit、MT 管理器）
  • 用编辑器的「查找」功能搜 spmb
  • 反复点「下一个」→ 最后一个就是目标链接
注意：spmb 是淘宝 SPM 埋点参数（页面追踪 ID），通常出现在 URL 的 &spmb= 或 ?spmb= 里。例如： https://pages-fast.m.taobao.com/...?...&spmb=46023237&...

四、Termux 被杀后再开

逐条执行：

termux-wake-lock
adb connect 192.168.1.108:5555
export ANDROID_SERIAL=192.168.1.108:5555
adb logcat -c
adb logcat -v time | grep -i "taobao\|sceneId\|deliveryId\|spmb"

五、手机重启后（无需电脑）

原生安卓优势：无线调试开关只要不关，重启后端口还会监听，不用回电脑。

重启后检查：

  • 设置 → 开发者选项 → 确认「无线调试」还是开启状态
  • 如果关了，重新打开
  • Termux 里重新 adb connect 即可

关键提示

  • IP 换成自己的（每台手机不一样）
  • 无线调试开关别关，关了就要重新配对
  • Termux 别被杀，加电池白名单 + termux-wake-lock
  • 配对端口和连接端口不一样：配对用小端口（43211 等），连接用 5555
  • 重启后 IP 可能变化，重新查一次

常见问题

Q: 找不到「无线调试」开关？
A: 1) 系统低于 Android 11，先升级
2) 厂商裁了（华为/荣耀全系没有）
3) 开发者选项没开启，先点 7 次版本号

Q: adb pair 提示 cannot connect？
A: 1) 配对端口错了，确认是详情页「使用配对码配对」里显示的端口
2) 配对码过期，重新生成一个
3) 手机和 Termux 必须是同一台手机（自抓自）或同一 Wi-Fi

Q: adb connect 提示 Connection refused？
A: 1) 无线调试开关被关了，重新开
2) 端口错了，无线调试详情页看连接端口（一般是 5555）
3) 手机熄屏太久 Wi-Fi 断了，亮屏重连

Q: adb devices 提示 unauthorized？
A: 第一次连接会有弹窗，勾「一律允许」→ 允许。配对过的就不会再弹。

Q: 抓不到淘宝日志？
A: 1) 确认开发者选项里「日志记录器缓冲区大小」不是关闭
2) 部分机型要开「USB 调试（安全设置）」才能读 logcat
3) MIUI 要在「开发者选项 → USB 调试（安全设置）」里允许 ADB 调试

Q: 配对码过期怎么办？
A: 配对码是一次性的，过了就重新点「使用配对码配对」生成新的。配对成功后这个码就不用了。

三套方案对比

| 方案 | 适用机型 | 是否需要电脑 | 重启后 | |------|---------|------------|--------| | 方案一：华为鸿蒙 | 鸿蒙 2/3/4.x（AOSP 兼容） | ✅ 必须 USB 激活 | 必须回电脑重新激活 | | 方案二：原生安卓（本教程） | 小米/OPPO/vivo/三星 Android 11+ | ❌ 全程不用 | 直接重连即可 | | 方案三：电脑 USB 抓 | 任意能 USB 调试的手机 | ✅ 全程插电脑 | 重插 USB |
